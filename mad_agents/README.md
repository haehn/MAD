# MAD Agents

Agent templates for **MAD — Multi Agent Development**.

## Structure

- `core/` — general-purpose roles usable across project types
- `software/` — software-engineering-specific roles

## Concept

Agents define **who an agent is and how it behaves**.

Skills define **what capabilities the agent can apply**.

Examples:

- `Worker.md + planning + communication`
- `Expert.md + research + evidence-evaluation`
- `Coder.md + debugging + testing + git`
