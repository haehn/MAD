# Progress Tracking

Use this skill to maintain an accurate operational view of a project.

## Track

- pending tasks
- active tasks
- completed tasks
- blocked tasks
- dependencies
- owners
- decisions
- risks
- next actions

## Rules

- Status should reflect evidence, not optimism.
- Mark work complete only when its completion criteria are satisfied.
- Surface blockers immediately.
- Avoid duplicating project history unnecessarily.
- Keep the current state concise.

## Output

Provide:
- overall status
- active work
- completed work
- blockers
- risks
- next actions
