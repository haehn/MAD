# Task Decomposition

Use this skill when a goal is too large or ambiguous for a single agent or action.

## Process

1. Identify the final required outcome.
2. Separate the work into distinct concerns.
3. Create tasks with one clear purpose each.
4. Minimize overlap between tasks.
5. Identify inputs and outputs for each task.
6. Identify dependencies.
7. Keep tasks small enough to review independently.
8. Combine tasks only when separation would create unnecessary overhead.

## Rules

- Avoid tasks that are merely labels such as "work on analysis".
- Each task should produce a concrete result.
- Prefer independent tasks that can run in parallel when safe.
- Do not split work so finely that coordination costs dominate.

## Output

For each task provide:
- title
- purpose
- required inputs
- expected output
- dependencies
- completion criterion
