# Documentation

Use this skill when knowledge must be preserved or communicated for future use.

## Process

1. Identify the intended reader.
2. Determine what the reader needs to accomplish.
3. Document prerequisites and assumptions.
4. Provide accurate procedures, examples, or explanations.
5. Use consistent terminology.
6. Remove obsolete or contradictory information.
7. Verify examples when practical.

## Rules

- Do not document behavior that has not been verified.
- Prefer concise, task-oriented documentation.
- Avoid unnecessary duplication.
- Keep volatile implementation details out unless needed.

## Output

Produce documentation that is:
- accurate
- concise
- maintainable
- directly usable
