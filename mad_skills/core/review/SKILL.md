# Review

Use this skill before accepting completed work.

## Process

1. Read the original objective and acceptance criteria.
2. Inspect the delivered result independently.
3. Check completeness and correctness.
4. Look for contradictions, omissions, or unintended consequences.
5. Verify important claims where practical.
6. Distinguish blocking problems from optional improvements.
7. Provide a clear acceptance recommendation.

## Decision

Use one of:
- PASS
- PASS WITH CONCERNS
- FAIL
- BLOCKED

## Rules

- Do not accept work merely because the author says it is complete.
- Keep findings concrete.
- Separate requirements from preferences.
- Avoid inventing issues unsupported by evidence.
