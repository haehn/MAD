# Decision Making

Use this skill when a project requires a choice between alternatives.

## Process

1. Define the decision.
2. Identify viable options.
3. Define relevant criteria.
4. Separate required criteria from preferences.
5. Compare each option against the criteria.
6. Identify risks, tradeoffs, and reversibility.
7. Prefer the simplest option that satisfies the important requirements.
8. Make a recommendation and explain why.

## Rules

- Do not manufacture false precision.
- Do not include obviously non-viable options for balance.
- Make tradeoffs explicit.
- Distinguish facts from judgment.

## Output

Return:
- decision
- options
- criteria
- comparison
- risks/tradeoffs
- recommendation
