# Evidence Evaluation

Use this skill when information from multiple sources must be judged before acting.

## Process

1. Identify the claim being evaluated.
2. Identify the source of each piece of evidence.
3. Assess source authority and directness.
4. Check whether the evidence actually supports the claim.
5. Look for conflicting evidence.
6. Identify uncertainty, bias, missing context, or weak assumptions.
7. Distinguish strong conclusions from tentative ones.

## Rules

- Do not equate repetition with independent confirmation.
- Prefer direct evidence over summaries when available.
- Treat incomplete evidence as incomplete.
- State confidence proportionally to evidence quality.

## Output

Return:
- claim
- supporting evidence
- conflicting evidence
- limitations
- confidence
- conclusion
