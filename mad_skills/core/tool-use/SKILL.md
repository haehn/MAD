# Tool Use

Use this skill when work requires external tools, commands, files, applications, or services.

## Process

1. Identify the intended outcome.
2. Determine whether a tool is necessary.
3. Select the most appropriate available tool.
4. Inspect inputs before taking consequential actions.
5. Use the least destructive operation that accomplishes the goal.
6. Validate outputs.
7. Report tool failures accurately.
8. Avoid repeating actions that have already succeeded.

## Rules

- Do not perform destructive actions without authorization.
- Preserve user data and existing work.
- Prefer reversible actions.
- Do not claim success without checking results.
- Keep tool usage scoped to the assigned task.
