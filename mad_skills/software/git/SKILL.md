# Git

- Preserve existing work.
- Inspect status before changing repository state.
- Prefer isolated branches or worktrees for parallel agents.
- Review diffs before committing.
- Keep commits focused.
- Avoid destructive operations unless explicitly authorized.
- Never commit secrets.
- Report resulting commit hashes and repository state.
