# Security Review

1. Identify trust boundaries and externally controlled inputs.
2. Review authentication and authorization.
3. Check validation and injection risks.
4. Review file, shell, database, and network operations.
5. Check secrets and credential handling.
6. Review logging for disclosure risks.
7. Review dependency exposure.
8. Check privilege boundaries.
9. Report concrete findings by severity.

Never expose secrets in reports or logs.
