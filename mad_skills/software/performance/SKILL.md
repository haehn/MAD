# Performance

1. Define the performance metric.
2. Establish a baseline.
3. Profile before optimizing.
4. Identify the dominant bottleneck.
5. Change one significant factor at a time.
6. Re-measure.
7. Check correctness and regressions.
8. Record benchmark conditions.

Do not optimize solely from intuition.
