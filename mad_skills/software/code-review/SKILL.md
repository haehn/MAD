# Code Review

1. Read the task and acceptance criteria.
2. Inspect the diff.
3. Verify the change addresses the requested behavior.
4. Check correctness and edge cases.
5. Look for unintended API or behavior changes.
6. Check consistency with repository conventions.
7. Review dependency changes.
8. Review test coverage.
9. Check performance, security, and compatibility risks when relevant.

Classify findings as BLOCKER, MAJOR, MINOR, or NOTE.
