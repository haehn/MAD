# Testing

1. Identify behavior and acceptance criteria.
2. Review existing test conventions.
3. Select relevant test types.
4. Cover normal behavior, edge cases, and failure modes.
5. Prefer deterministic automated tests.
6. Run focused tests first.
7. Run broader regression tests when warranted.
8. Distinguish product, test, and environment failures.
9. Report evidence clearly.

Never weaken a valid test just to make it pass.
