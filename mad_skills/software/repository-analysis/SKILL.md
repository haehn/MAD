# Repository Analysis

1. Inspect top-level files and directories.
2. Identify languages, frameworks, build systems, package managers, and tests.
3. Read primary documentation and configuration.
4. Locate entry points and major modules.
5. Trace components relevant to the assigned task.
6. Identify APIs, dependencies, data flows, and conventions.
7. Inspect tests and examples.
8. Identify generated, vendored, or protected files.
9. Report likely change locations and unresolved questions.

Prefer existing project patterns and read before editing.
