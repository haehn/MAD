# Debugging

1. Reproduce the failure.
2. Record the exact error and environment.
3. Reduce to a minimal reproducer when practical.
4. Trace the relevant execution path.
5. Form evidence-based hypotheses.
6. Test hypotheses one at a time.
7. Identify the root cause.
8. Implement the smallest safe fix.
9. Add or update a regression test.
10. Re-run relevant tests.

Do not suppress errors merely to make tests pass.
