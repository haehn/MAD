# Dependency Analysis

1. Determine whether existing dependencies already solve the problem.
2. Verify required versions.
3. Check transitive impact.
4. Evaluate maintenance and release stability.
5. Consider licensing and security.
6. Estimate integration and migration cost.
7. Prefer existing or standard capabilities when sufficient.

Do not add dependencies for trivial functionality.
